# Vut Display Conversion

## 1. Purpose

Vut formats values for `out`, `print`, and template interpolation without
reflection, runtime type metadata, or runtime name lookup. A value is turned
into text by a **compile-time display conversion** driven by its static type.

```vut
out(User(a = 1))     # User(a = 1)
out(@(1, 2, 3))      # [1, 2, 3]
out("user=$user")    # interpolation uses the same conversion
```

## 2. Displayable types

```text
scalars     int, float, and sized numerics
str         bare at the top level, quoted when nested
bool        true / false
bytes       [104, 105]
list(T)     [element, element, ...]
array(T,N)  [element, element, ...]
data        Name(field = value, ...)
enum        variant / variant(payload, ...)
result      ok(value) / err(error)
opaque      <function>, <vutcon>, <resource>, <future>, <dyn>, <ptr>
```

## 3. Format rules

| Type | Output |
| --- | --- |
| `int`, `float`, numeric | decimal text |
| `bool` | `true` / `false` |
| `str` (top level) | the text itself |
| `str` (nested) | `"quoted"` |
| `bytes` | `[b0, b1, ...]` |
| `list` / `array` | `[a, b, c]`, empty `[]` |
| `data` | `Name(field = value, ...)`, unit `Name()` |
| `enum` | unit `variant`; payload `variant(a, b)` |
| `result` | `ok(value)` / `err(error)` |

Nested strings inside aggregates are quoted and separated by `, `.

## 4. Invocation

`out`/`print` accept zero or more displayable arguments joined by single
spaces. `out` appends a newline, `print` does not.

```vut
out(1, true, "x")   # 1 true x
out()               # a single newline
```

Template interpolation `$name` and `$(expression)` uses the same conversion for
non-`str` operands.

## 5. Guarantees

- The conversion is generated by the compiler from static types.
- No reflection, no runtime type metadata, no runtime name lookup.
- Generated functions run through the normal ownership/drop pipeline, so
  printing does not leak.
- A per-type display function is generated once and reused; recursive
  aggregates call it rather than expanding inline.

## 6. Deferred

- `map(K, V)` is displayed as `<map>` (map value access is `optional`).
- A user-defined `to_str`/display override is not supported yet.

## 7. Non-displayable values

- Optional `T?` values are not displayable directly: an optional used where a
  value is required is `E1007` (`specs/optional/00-overview.md`). Narrow with
  `if value != null` or a `match` null arm first.
- `dyn` is displayed as the opaque `<dyn>` form (see §2). There is no runtime
  type-directed display of the concrete boxed value.
